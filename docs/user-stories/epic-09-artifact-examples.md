## US-9.1 Read a professional example

**As** a product team  
**I want** worked examples of the core Scrum, Agile, and SAFe artifacts  
**So that** a new room starts from the same language the frameworks already use  

**Acceptance criteria**

- [ ] The room offers eight artifacts: PRD, Lean Business Case, epic, feature, user stories, Product Backlog, Sprint Backlog, and Increment & Definition of Done  
- [ ] Each artifact has an example for the Unified Agent Platform, the Contact Center Platform, and CS data products  
- [ ] User stories name the user, the outcome, the reason, and acceptance criteria  
- [ ] The epic states the hypothesis and the evidence that would prove it  
- [ ] The Feature states a benefit hypothesis, acceptance, and a story split  
- [ ] The Lean Business Case includes MVP scope, leading indicators, and a WSJF signal  
- [ ] Each example names the personas and maps stakeholders with RACI; one person is accountable  
- [ ] The Product Backlog has a Product Goal and one order  
- [ ] The Sprint Backlog has a Sprint Goal, and the selected items are a forecast  
- [ ] The Increment names what is Done and the Definition of Done that made it Done  
- [ ] Switching artifact or product is a shared op; prose is derived, not stored on the room
