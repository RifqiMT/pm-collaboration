# Epic E7 — Product direction

**Goal:** The team can write a product vision or a product strategy in a professional framework and read it back as one statement.

---

## US-7.1 Choose a vision or strategy framework

**As** Priya / Maya  
**I want** to pick a known framework for a vision or a strategy  
**So that** the room is filling in a real method, not a blank page  

**Acceptance criteria**

- [ ] Vision offers the extended Product Vision Board and a positioning statement  
- [ ] The vision board includes competitors, revenue, costs, and channels  
- [ ] The positioning statement includes the product name and reads back as one sentence  
- [ ] Strategy offers Playing to Win, the strategy kernel, and DHM  
- [ ] Playing to Win includes where you will not play and what would have to be true  
- [ ] The kernel includes the crux and what the policy rules out  
- [ ] DHM includes a proxy metric and a tactic  
- [ ] The selected framework shows how to fill it in  
- [ ] Switching framework keeps answers already written  
- [ ] The room reads the current answers back as one statement  
- [ ] A prompt from another framework is rejected until that framework is selected
