## Goals

- Start a retro or review in under a minute and share one code  
- Control section timing so the meeting finishes on schedule  
- Keep brainstorm psychologically safe, then surface themes fairly  
- Leave with owned actions or a clear release decision  
- Export a record for the team wiki without retyping  

## Frustrations

- Sticky-note tools that leak drafts before discuss  
- Tools that mix voting, notes, and actions on one noisy board  
- Scoring spreadsheets that disagree with the phone screenshot  
- Accounts and SSO friction for a 45-minute ritual  

## Behaviors in TeamCompass

- Creates the room; becomes `hostId`  
- Picks template and icebreaker; may customize This or That pairs  
- Advances phases; starts 3/5/8 minute timers  
- Chooses discuss walk (status vs author) and focuses groups  
- Sets vote budget; drives action assignment  
- Opens Summary and downloads CSV  

## Needs from the product

| Need | Product response |
| --- | --- |
| Host authority | Host-gated phase, icebreaker, discussion mode |
| Clear sections | Each retro phase shows only that section’s work |
| Timing | Per-section countdown + stopwatch |
| Trustworthy privacy | Server-side brainstorm filtering |
| Closure | Actions + CSV; review ship/iterate/hold |

## Success looks like

A 60-minute retro ends with three owned actions, a CSV in Slack, and no one saying “my note showed too early.”
